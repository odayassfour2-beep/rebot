# برنامج الأستاذ عدي عصفور — تطبيق سطح المكتب

يمكن تشغيل البرنامج كتطبيق سطح مكتب بواسطة Electron، أو فتح `index.html` مباشرة في المتصفح.

## إنشاء نسخة تثبيت لويندوز

1. ثبّت Node.js على جهاز التطوير.
2. افتح سطر الأوامر في مجلد المشروع.
3. نفّذ:

   ```bash
   npm install
   npm start
   ```

   للتأكد من تشغيل التطبيق.

4. لإنشاء ملف تثبيت ويندوز (NSIS) نفّذ:

   ```bash
   npm run dist:win
   ```

5. ستجد ملف التثبيت الناتج داخل مجلد `release/`.

يمكن استخدام `npm run dist:mac` على جهاز macOS أو `npm run dist:linux` على Linux لإنتاج حزمة النظام المناسب. بناء كل نظام يُفضّل إجراؤه على النظام نفسه.

## حفظ البيانات

يحفظ التطبيق بياناته في تخزين Chromium المحلي الخاص بتطبيق Electron على جهاز المستخدم، وتبقى محفوظة عند إغلاق التطبيق وفتحه مجدداً. البيانات ليست قاعدة بيانات سحابية ولا تتم مشاركتها تلقائياً مع أجهزة أخرى. استخدم ميزة النسخة الاحتياطية داخل البرنامج لحفظ نسخة من البيانات ونقلها أو استعادتها.

واجهة البرنامج تعتمد على موارد CDN لبعض الميزات (مثل Tailwind CSS وSheetJS والخطوط والأيقونات)، لذلك يلزم اتصال بالإنترنت لتحميل تلك الموارد. لا يتطلب التطبيق خادماً PHP لتشغيل نسخة سطح المكتب.
